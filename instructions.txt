Pre-setup:
Make the end-of-line-sequence of run_init_py.sh to LF to ensure that bash interprets the shell script correctly.

Inside the Dockerfile:
# Base the image on MariaDB version 10.3
# Install Python and dependencies
# Install the mariadb package (version 1.0.11 for compatibility reasons) with pip from the requirements.txt file
# Copy the Python script (Ski_Hotel_Init.py) and the shell wrapper (run_init_py.sh)
# Execute the shell script
	->The shell script executes the python file

Execute the following commands in the correct directory:
docker build -t ski_hotel_db .
	-> Build the image from the Dockerfile
docker run -d --name ski_hotel_assignment -p 3306:3306 ski_hotel_db
	-> Create the container and run the image on it
docker exec -it ski_hotel_assignment mysql -u root -p
	-> Enter the container and interact with its shell
