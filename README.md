# DBS_S2_Assignment
Database Systems Assignment for Semester 2 of the IMC Bachelor’s Program in Computer Science

The purpose of the assignment is to model a ER Diagram for a hotel database that specializes in
single customers that are looking for a place to stay during their active vacation that usually
involves skiing. The key functionalities that the database should manage include managing
reservations, tracking packages, ski pass purchases, and having data available to query for
analytics.
